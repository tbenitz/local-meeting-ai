Local Meeting AI

Live transcription, transcript cleanup, and meeting notes run in your browser with WebGPU. There is no meeting-AI backend. Hugging Face is used only for the first model download; after that the files stay in the browser cache.

Open the live app

  1. Use current Chrome or Edge with WebGPU.
  2. Turn on Pages once: repo Settings → Pages → Source = GitHub Actions, then rerun the failed deploy workflow.
  3. Upload the full single-file app as index.html in this repo (replace this landing page) so recording / notes load here.
